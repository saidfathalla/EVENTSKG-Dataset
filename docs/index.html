Dataset Statistics

Overview of current and previous release characteristics.

Latest Release (Version 2018-11)

The new release is a Linked Dataset based on the updated SEO ontology. EVENTSKG contains 73 event series across eight computer science communities identified via the ACM Computing Classification System: AI, SE, WEB, SEC, IS, CSO, HCC, and TOC.

Previous Releases

Version 2018-01 (EVENTSKG-40): Specification of 40 top-prestigious event series (Details | Turtle).

Version 2018-01 (EVENTS): Specification of 25 event series (Details).

Description & Use Cases

EVENTSKG helps conference steering committees assess event progression over time, enables authors to find high-impact venues, and provides publishers with visibility into proceedings performance.
