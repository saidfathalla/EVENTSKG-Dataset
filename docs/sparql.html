EVENTSKG Public SPARQL Explorer

Run basic SPARQL SELECT queries against the EVENTSKG Turtle dataset in your browser. Query execution uses parsed triple patterns and variable joins; it is not a remote SPARQL endpoint.

Supported query features

SELECT projections, PREFIX declarations, basic graph patterns, joins across multiple triple patterns, variables, IRIs, prefixed names, literals, semicolon/comma shorthand, DISTINCT, and LIMIT. FILTER, OPTIONAL, UNION, aggregates, property paths, and remote SERVICE queries are not implemented by this lightweight browser evaluator.
