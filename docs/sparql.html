EVENTSKG SPARQL Explorer

Run SPARQL 1.1 queries against EVENTSKG 3.0 directly in your browser. The dataset is downloaded once and queried locally with the Oxigraph engine, so FILTER, OPTIONAL, UNION, aggregates (COUNT, AVG, …), GROUP BY, ORDER BY, subqueries and property paths all work. The enriched edition adds types and labels for all resources and Wikidata links for all places; the generated edition contains only the curated facts.

Common prefixes are predeclared: rdf, rdfs, owl, xsd, skos, schema, seo, eventskg, conference-ontology, dbpedia-owl, dbo, dbr, wd, dcterms, void, prov. Press Ctrl+Enter to run.

Supported queries

SELECT, ASK, CONSTRUCT and DESCRIBE queries in SPARQL 1.1, including FILTER, OPTIONAL, UNION, MINUS, BIND, VALUES, aggregates, GROUP BY, HAVING, ORDER BY, subqueries and property paths. The data are queried in your browser; SERVICE calls to remote endpoints and updates are not available.
